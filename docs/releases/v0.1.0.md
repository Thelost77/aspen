# Aspen v0.1.0

First public release of Aspen, a keyboard-first terminal client for Apple Messages on macOS.

## Highlights

- Browse existing iMessage and SMS conversations
- Resolve local Contacts names through read-only databases
- Read and page message history with responsive split and narrow layouts
- Filter conversations and loaded messages
- Load complete conversation history with cancellable keyset pagination
- Compose direct text messages with per-chat drafts
- Navigate with keyboard or mouse locally and over SSH
- Render native inline images in Ghostty and iTerm2
- Convert HEIC/HEIF attachments locally for terminal display

## Sending safety

- Sends target the exact existing Messages `chat.guid`
- GUID and text cross into AppleScript as separate `argv` values
- No participant, display-name, phone, email, or list-index fallback
- Duplicate sends are suppressed while a send is pending
- Failed sends preserve drafts and provide permission guidance
- Group and RCS sending remain disabled

## Privacy

- Messages and Contacts SQLite connections are read-only with `query_only=1`
- No message cache, telemetry, analytics, or network service
- Logs exclude message and contact content
- Runtime directories and files use owner-only permissions
- Image decoding, conversion, and rendering stay local

## Installation

```sh
go install github.com/Thelost77/aspen@v0.1.0
```

## Requirements

- macOS with Messages.app configured
- Go 1.25.6 or newer when installing from source
- Full Disk Access for the process launching Aspen
- Messages Automation permission for sending
- Ghostty or iTerm2 for inline images

## Known limitations

- Existing conversations only
- Text sending only
- Group and RCS sending disabled
- Attachments are view-only
- No background polling
- iTerm2 hides partial images while scrolling because OSC 1337 cannot crop source regions
- Apple Messages and Contacts use private local schemas that can change with macOS
